Installing
==========

PyPI Installation
-----------------

For ordinary use, install SolRaT from PyPI:

.. code-block:: bash

   pip install solrat

Development Installation
------------------------

For advanced modifications, forks, or local development, clone the repository and install it in editable mode:

.. code-block:: bash

   git clone https://github.com/yakovkinii/SolRaT.git
   cd SolRaT
   pip install -e .

This keeps the Python environment connected to the local source tree, so edits to atomic data, SEE rates, RTE coefficients, or demos are picked up without reinstalling the package.
